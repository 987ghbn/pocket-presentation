# Карманный генератор презентаций

Текст доклада → файл PowerPoint (.pptx). Работает на телефоне и компьютере, без сервера и без регистрации.

## Что внутри
- `index.html` — само приложение (вставляете текст, нажимаете «Скачать .pptx»)
- `manifest.json`, `sw.js`, `icon.svg` — чтобы установить на экран телефона и открывать без интернета (кроме первого запуска)
- `make_pptx.py` — то же самое для компьютера из командной строки

## Как запустить на компьютере
1. Папку `pocket-presentation` положите куда угодно, откройте `index.html` двойным щелчком.
2. Нужен интернет при первом открытии (подгружается библиотека PptxGenJS).

## Как запустить на телефоне
Телефону нужен адрес сайта. Самый простой бесплатный способ — Netlify Drop:
1. На компьютере откройте app.netlify.com/drop и перетащите туда папку `pocket-presentation`.
2. Получите ссылку вида `https://что-то.netlify.app` — открывайте её на телефоне.
3. Android (Chrome): меню ⋮ → «Установить приложение». iPhone (Safari): «Поделиться» → «На экран Домой».
Альтернатива: GitHub Pages (репозиторий → Settings → Pages).

## Python-версия
    pip install python-pptx
    python make_pptx.py doklad.txt 12

## Как приложение делит текст
1. Первая строка → название (если не задано вручную).
2. Заголовки: строки с `#`, «1. …», «Глава …» или короткие строки без точки в конце.
3. Если заголовков нет — каждый абзац становится слайдом.
4. Предложения → пункты (до 5 на слайд, длинные сокращаются).
5. Не влезает в «максимум слайдов» — берётся меньше предложений на раздел.
